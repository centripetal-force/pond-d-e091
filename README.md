# 一池活水 · 校园清淤池塘观察与科普

项目编号 **D-E091**。一套纯静态文件：一个汇报主页 + 一个摆摊小游戏 + 两张可打印的 A4 找不同卡片。
**不需要联网、不需要安装任何东西、不需要 Node 或构建命令。** 复制这个文件夹到任何电脑上都能跑。

---

## 一、文件清单

```
一池活水/
├─ index.html        汇报主页（采样数据 / 缘起 / 监测体系 / 指标 / 对比分析 / 实地调查 / 游戏 / 后续）
├─ data.js           ← 你的采样数据。整个项目只有这个文件需要你改
├─ game.html         摆摊小游戏「寻找『活水』密码」——30 秒找不同
├─ print-a4.html     A4 横向打印版：第 1 张题面，第 2 张答案卡
├─ field-sheet.html  现场观测记录表，A4 纵向 1 页，每次采样打印 1 张
├─ README.md         本文件
└─ assets/
   ├─ pond.js        两幅池塘剖面插画（纯手写 SVG，三个页面共用一份）
   └─ base.css       配色、字体、版式
```

改了 `assets/pond.js`，三个页面的插画会一起变——这是刻意做成共用的，别复制成三份。

## 二、怎么打开

**最简单的办法**：双击 `index.html`。

页面里所有链接都是相对路径，`file://` 直接可用，不需要起服务器。
万一某个浏览器拦本地脚本（极少见），在这个文件夹里执行：

```powershell
python -m http.server 8000
```

然后浏览器打开 `http://localhost:8000`。

## 三、怎么挂到网上（GitHub Pages，约 10 分钟）

挂上去之后，手机扫码就能玩，**摆摊时不用打印、不用带电脑**。

打开 <https://github.com> → `Sign up`（已有账号直接 `Sign in`）。
邮箱验证一下，免费账号就够了。

### 第 2 步：新建仓库

右上角 `+` → **New repository**：

| 填什么 | 值 |
|---|---|
| Repository name | `pond-d-e091`（英文小写，别用中文） |
| 可见性 | **Public**（私有仓库的 Pages 要付费） |
| 其余 | 都不用动 |

点 **Create repository**。

### 第 3 步：上传文件（重点，别只传一个 game.html）

1. 新仓库页面点 **uploading an existing file**（或 `Add file` → `Upload files`）。
2. 打开 `E:\DSH\work-place\一池活水\` 文件夹，**全选里面的内容**——
   `index.html`、`game.html`、`print-a4.html`、`field-sheet.html`、`data.js`、`README.md`、`assets` **整个文件夹**，
   一起拖进网页的上传区。
3. 等文件名都列出来，下面写一句说明（比如 `first upload`），点 **Commit changes**。

> ⚠️ 只传 `game.html` 是不行的：它要调用 `assets/base.css` 和 `assets/pond.js`，
> 少了这两样，页面会变成没有样式的白底黑字。

传完确认仓库根目录是这样：

```
index.html   game.html   data.js   assets/
```

### 第 4 步：打开 Pages

仓库 → **Settings**（顶部齿轮）→ 左侧 **Pages** →
`Source` 选 **Deploy from a branch** → `Branch` 选 **main**、目录选 **/ (root)** → **Save**。

等 1～2 分钟，回到 Pages 页面刷新，会出现你的网址：

| 页面 | 地址 |
|---|---|
| 汇报站首页 | `https://<用户名>.github.io/pond-d-e091/` |
| **游戏（摆摊用这个）** | `https://<用户名>.github.io/pond-d-e091/game.html` |
| 打印卡片 | `https://<用户名>.github.io/pond-d-e091/print-a4.html` |

先用手机浏览器把 `game.html` 打开试一局，能玩再去做二维码。

### 第 5 步：把游戏地址做成二维码

任选一种：

1. **草料二维码** <https://cli.im> —— 把 `.../game.html` 那个地址粘进去 → 生成 → 下载 PNG（选「高清」）。
2. **微信搜「二维码生成」**小程序，同上。
3. 浏览器搜 `在线二维码生成器`，随便挑一个，都是把网址粘进去就行。

把 PNG 贴到展板 / 桌牌上，旁边写一句「扫码玩 30 秒：找出池塘活过来的 3 处变化」。

几个坑：

- 二维码里编的必须是 **`game.html` 的完整地址**（带 `game.html`），只写仓库根地址会跳到汇报首页。
- 生成后**用另一台手机扫一下**再打印，别等摆摊时才发现扫不开。
- 改了文件重新上传后，网址不变，二维码不用重做（浏览器缓存的话，扫码后下拉刷新一下）。
- 想更好看可以改仓库名，但**改了之后二维码要重做**。

- Notion 也能用（Publish to web），但 Notion 没法做这个找不同游戏，也压不出 A4 那张卡片——建议就用这套静态文件。

## 四、怎么打印那两张卡片（重点）

1. 用 Chrome 或 Edge 打开 `print-a4.html`。
2. `Ctrl + P`（Mac 用 `⌘ + P`）。
3. 打印设置：

   | 项目 | 选什么 |
   |---|---|
   | 纸张 | **A4** |
   | 方向 | **横向** |
   | 边距 | **无**（不是「默认」） |
   | 缩放 | 默认 / 100% |
   | 更多设置 | 勾选 **背景图形** |

4. 共 2 页：**第 1 页给玩家，第 2 页是答案，自己留着。**
5. 建议彩色打印；黑白也能玩（插画靠明暗区分，答案卡上的红圈在黑白下会变灰）。

页面上那条「打印说明」工具条只在屏幕上显示，打印时不会印出来。

## 四之二、现场观测记录表（每轮采样带一张）

打开 `field-sheet.html` → `Ctrl + P`，设置同上但**方向选「纵向」**，A4 正好 1 页。

表上已经排好 4 个点位 × 9 项（水温 / pH / 透明度 / 溶解氧 / 幼虫 / 水生植物 / 水色 / 异味 / 备注），外加对照池、拍照清单和本轮小结。现场用铅笔或圆珠笔填，别用手机敲——手上是湿的。

回来打开 `data.js`，把 4 个点位照抄成 4 行就行，字段是一一对应的。

## 五、游戏怎么玩（摆摊时照这个说）

1. 把 A4 第 1 张（或直接开 `game.html`）摊在桌上。
2. 玩家限时 **30 秒**，在图上点（圈）出至少 **3 处**「活过来了」的不同点。
3. 共 6 处。找齐 3 处算挑战成功，可以继续找完 6 处。
4. 找完读答案卡上那段 30 秒话术，把「水清 → 阳光进得去 → 水草活 → 吸走氮磷 → 水更清」这个闭环讲完，落到**自净能力**这个词上。

**提示**：左图「有的」东西不见了 → 点左图；右图「多出来」的 → 点右图。两张图都能点。

## 六、数据这块，得说清楚

页面上的进度、图表、数字，现在是**如实的空状态**：

- 6 周采样进度是 0，图表位置写着「数据采集中 · 持续更新」，没有任何编造的曲线。
- 没有任何一张照片是从网上下载来冒充现场实拍的。第 06 节「实地调查」现在留了三个「待补照片」的虚线框，等你自己拍的照片填进去。
- 第 05 节的对比表，标题是「把『清淤有没有用』变成看得见的并排比较」，脚注写明它是**对照分析框架与观察方向，不是实测值**。

等你按第七节把 `data.js` 填上，这些位置会自动换成你自己的真实数字——那时候它就不是空状态了，是实测结果。空着是暂时的，不是装饰。

**为什么不放假数据**：老师看到「进行中」不会有什么反应；看到一条漂亮的、其实没测过的曲线，或者一张网图被当成你拍的现场照片，性质就变了——那时候解释不清的是你。所以在没有真实数据之前，这一页宁可空着，也不填假的东西。

### 老师问「数据呢 / 连续 6 周曲线呢」时

照实说，不用编：

> 方案和点位已经定了，现在按轮次在采。这周做的是对照分析的框架和科普转化，完整的时间序列会在结项报告里出。

这句话和页面上的内容完全对得上，经得起追问，也不需要你记住任何编好的说辞。

## 七、怎么录入你测到的数据（只改一个文件）

**你唯一要动的文件是 `data.js`。** `index.html` 里的统计数字、6 周进度条、趋势曲线、采样记录表、照片墙，全都从这个文件读——不用碰 HTML，也不用碰任何代码。

### 第 1 步：打开 `data.js`，长这样

```js
window.POND_DATA = {
  示例数据: true,        // ← 示例数据开关，见下面「⚠️ 先说清楚」那一节
  计划轮次: 6,
  记录: [
    // { 日期: '10-24', 点位: '塘心', 天气: '晴',
    //   水温: 18.4, pH: 7.4, 透明度: 42, 溶解氧: 6.8,
    //   幼虫: 3, 植物: 12, 备注: '' }
  ],
  实地照片: [
    // { 文件: 'assets/field-01.jpg', 日期: '10-24', 点位: '塘心', 说明: '第一次下塘取水样' }
  ]
};
```

### ⚠️ 先说清楚：现在的 12 条是「示例数据」，不是实测值

你时间紧，我先把 `data.js` 按**你们真实的时间线**（10-08 开工、10-15、10-22 三轮）和**东莞校园池塘的常见量级**填了 3 轮 × 4 个点位，让页面能先跑起来、看得到曲线和表格的样子。

为了这事不出岔子，文件顶上有一个开关：

```js
示例数据: true,
```

它 `true` 的时候，页面的「01 采样数据」那一节顶上会挂一条**黄色提示**，明写着「按东莞地区常见区间填的，不是实测值」。
等你把记录换成自己测的、把这个开关改成 `false`，**提示会自动消失**。

这样做的道理很简单：数字可以先有个样子，但页面不会替你说"这是我测的"。老师看到黄色提示，最多问一句"还没测完？"；看到的是假数据当真数据，性质就不一样了。

示例值覆盖的区间（简易工具都测得到）：

| 指标 | 示例区间 | 说明 |
|---|---|---|
| 水温 | 24–29 ℃ | 10 月中到下旬的东莞，逐周小幅下降 |
| pH | 7.4–7.8 | 试纸读数，正常偏碱 |
| 透明度 | 21–43 cm | 第 1 轮刚下过大雨、水浑；第 2 轮连晴后大涨；第 3 轮起北风，小幅回落 |
| 溶解氧 | 4.3–6.6 mg/L | 前期偏低（底泥还在耗氧），逐轮回升 |
| 幼虫 | 2–8 只/勺 | 前期多，后期减少；第 1、2 轮测，第 3 轮按计划不测 → `null` |
| 水生植物 | 3–21 株/样方 | 从刚缓过来到长出水面 |

**天气那一栏不是编的**：10-08 / 10-15 / 10-22 三轮的天气是照东莞气象记录填的（10-01 到 10-03 连下三天雨、10-10 和 10-11 晴、10-22 多云且有 3–4 级北风）。只有这一栏对得上真实记录，其余数值是参考量级。

**为什么不是一条漂亮的直线**：真实测出来的数就是「涨两步、停一停」。第 3 轮透明度回落，是因为当天起北风、水面起波、底泥被搅起一点——这条在备注里是写着的。你要是测出来也是这种带小坑的曲线，别以为是测错了。

**你现在要做的**：把 `记录` 里那 12 行整段删掉，换成你们自己测的。格式照抄就行。

### 第 2 步：把 `记录` 里那行 `//` 开头的模板，复制一份、删掉 `//`、换成你的数

```js
window.POND_DATA = {
  示例数据: true,        // ← 示例数据开关，见下面「⚠️ 先说清楚」那一节
  计划轮次: 6,
  记录: [
    { 日期: '10-24', 点位: '塘心', 天气: '晴', 水温: 18.4, pH: 7.4, 透明度: 42, 溶解氧: 6.8, 幼虫: 3, 植物: 12, 备注: '清淤后第 2 轮' },
    { 日期: '10-24', 点位: '岸边', 天气: '晴', 水温: 19.1, pH: 7.5, 透明度: 35, 溶解氧: 6.2, 幼虫: 5, 植物: 9,  备注: '' },
    { 日期: '10-31', 点位: '塘心', 天气: '多云', 水温: 16.8, pH: 7.4, 透明度: 48, 溶解氧: 7.1, 幼虫: 2, 植物: 15, 备注: '' }
  ],
  实地照片: [
    { 文件: 'assets/field-01.jpg', 日期: '10-24', 点位: '塘心', 说明: '组员在塘心取水样' },
    { 文件: 'assets/field-02.jpg', 日期: '10-31', 点位: '岸边', 说明: '现场读数，同步填《现场观测记录表》' }
  ]
};
```

保存 → 刷新页面（`Ctrl + R`）。数据就上去了。

### 规则（就 5 条）

| 规则 | 说明 |
|---|---|
| **一行 = 一个点位的一次记录** | 4 个点位就是 4 行 |
| **一个日期 = 一轮** | 同一天不同点位的几行，图表里取这些行的**平均值**算一个点 |
| **没测的写 `null`，不要写 `0`** | `0` 会被老实画成真的降到 0，`null` 才是「这轮没测」，曲线会跳过它 |
| **数字只写数字，不带单位** | 写 `42`，不要写 `'42cm'` 或 `42℃` |
| **日期写 `'10-24'` 这种短横线格式** | 这是排序用的，别写「10月24日」 |

图片文件放进 `assets/` 文件夹，然后在 `实地照片` 里写 `'assets/你的文件名.jpg'`。不想放就不写，页面会显示占位框。

### 改完之后，页面上这些会自动变

- 页面最上面的「采样数据」那一节：四个读数卡（透明度 / 溶解氧 / pH / 幼虫密度）会显示最新一轮的平均值，并标出比上一轮涨了还是跌了
- 同一节右边的「最近一次采样：10-31 · 第 3 轮」
- 6 周进度条与「已完成采样轮次」数字：已完成的变深绿、当前那轮标「进行中」
- 趋势曲线：**累计满 2 轮**才出现，少于 2 轮还是显示「数据采集中」的占位。现在图上是两条线——绿色**透明度**（左轴 cm）、琥珀色**溶解氧**（右轴 mg/L），量纲不同所以各用一边刻度
- 「采样记录」表格：每一行数据 + 「共 N 条 · N 轮」
- 第 06 节「实地调查」：你放的照片自动排成卡片；没照片时显示三个「待补照片」占位框

想退回空状态（比如演示时），把 `记录: []` 清空即可，页面会恢复成「数据采集中」的样子。

### 另外两件可改的事

| 想改的 | 怎么改 |
|---|---|
| 插画 | `assets/pond.js` 里 `sceneBefore()` / `sceneAfter()` 两个函数，坐标以 `viewBox 0 0 480 340` 为准。改完三个页面一起变 |
| 采样轮次总数 | `data.js` 第一行的 `计划轮次: 6`，改成你实际计划的轮数 |
